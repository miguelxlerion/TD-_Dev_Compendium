Diseño Conceptual

La piedra angular de todo el pipeline

El concept art no es solo dibujar personajes bonitos: es un documento técnico-artístico que define apariencia, personalidad, paleta de materiales y estados de transformación. Para proyectos como Total Darkness, debe anticipar las necesidades técnicas de transformación ética y expresión emocional.

El proceso incluye: investigación visual (moodboards), bocetos exploratorios de siluetas, character sheets con múltiples vistas, estudios de expresión y transformación, y especificaciones de materialidad.

Entregables de la fase

  • Moodboards curados (Photoshop, Pinterest, Figma)
  • Bocetos exploratorios (Fresco, Sketchbook)
  • Concept art final (Photoshop, Corel Painter)
  • Character sheets con vistas múltiples
  • Variaciones de estado (transformaciones éticas)

Modelado High-Poly en ZBrush

El estándar de la industria AAA

El modelo de alta poligonación captura todos los detalles finos: arrugas, cicatrices, texturas de tejidos, imperfecciones. Se trabaja con millones de polígonos sin restricciones de rendimiento. ZBrush es el estándar universal en estudios AAA, aunque Blender (con Multiresolution Modifier) es una alternativa creciente.

El workflow híbrido típico: bloqueo inicial en Maya/Blender → importación a ZBrush → refinamiento con DynaMesh y herramientas de escultura → subdivisión para añadir detalles finos.

Aspectos clave del High-Poly

Retopología, UV y Baking

La columna vertebral de la optimización

Retopología

Crear una malla low-poly limpia a partir del high-poly. Topología con quads, loops siguiendo anatomía, sin n-gons.

Herramientas: RetopoFlow (Blender), ZRemesher (ZBrush), Quad Draw (Maya)

Mapeo UV

Desplegar la malla 3D en 2D. Principios: densidad de texel uniforme, empaquetado eficiente, sin superposiciones.

Herramientas: UVPackmaster, Blender UV, RizomUV

Baking de Mapas

Transferir detalles del high al low-poly mediante mapas: Normal, AO, Height/Displacement.

Herramientas: Marmoset Toolbag, Substance Painter, xNormal

Texturizado PBR

Substance Painter y el flujo de trabajo físico

El estándar moderno AAA es el Renderizado Basado en Físicas (PBR). Simula el comportamiento real de la luz con parámetros como rugosidad y metalicidad, garantizando consistencia bajo cualquier iluminación.

Adobe Substance Painter es la herramienta estándar, con sistema de capas tipo Photoshop, smart masks para desgaste automático, y generación procedural.

📦 Mapas PBR esenciales

  • AlbedoColor base sin iluminación
  • NormalSimula detalles geométricos
  • MetallicMetal vs no-metal (0 o 1)
  • RoughnessBrillo vs mate
  • AOOclusión ambiental

Channel Packing: Técnica clave en URP/HDRP que empaqueta Metallic, Roughness y AO en los canales R, G, B de una sola textura RGBA. Reduce drásticamente el consumo de VRAM y las llamadas a dibujar.

Rigging, Skinning y Blend Shapes

El alma de la animación

El rigging crea el esqueleto interno y el sistema de controles. En Unity existen dos tipos principales: Humanoid (para personajes humanos, permite retargeting de animaciones) y Generic (para criaturas, robots, rigs personalizados).

El skinning asigna pesos a cada vértice. La técnica avanzada Dual Quaternion Skinning (DQS) elimina artefactos de deformación en articulaciones. Las Blend Shapes permiten expresiones faciales y transformaciones éticas (cruciales para Total Darkness).

🎭 Rigging facial

Combina dos técnicas: huesos para poses generales y blend shapes para expresiones detalladas.

Herramientas: Maya (estándar AAA), Blender (Rigify), FaceBuilder

Integración en Unity

Animator, Blend Trees, State Machines

El Animator Controller gestiona la máquina de estados de animación. Se usan Sub-State Machines para organizar estados lógicamente (Locomoción, Ataques, Estados Éticos). Los Blend Trees mezclan animaciones suavemente basadas en parámetros como velocidad.

Animation Events sincronizan eventos (sonidos, partículas, daño) con fotogramas específicos. Root Motion permite que la animación dicte el movimiento del personaje. State Machine Behaviours ejecutan código desde estados específicos del Animator.

⚙️ Configuración de importación FBX

  • Rig Type: Humanoid (retargeting) o Generic
  • Optimize Game Objects: habilitar para humanoides
  • Read/Write Enabled: solo si se manipula la malla en código
  • Mesh Compression: reduce tamaño en memoria
  • Anim Compression: equilibrar tamaño vs precisión

Optimización y Preparación Final

LODs, GPU Instancing, Draw Calls

LOD (Level of Detail)

Renderizar versiones de menor poligonaje según la distancia. Unity tiene sistema integrado con LODGroup. Estándar AAA: 3-4 niveles por personaje.

GPU Instancing

Renderizar múltiples copias del mismo modelo con una sola draw call. Ideal para multitudes y objetos repetidos.

Texture Atlasing

Empaquetar múltiples texturas pequeñas en una grande. Reduce drásticamente las draw calls.

Caso de Estudio: Total Darkness

Aplicando el pipeline a un proyecto narrativo complejo

Total Darkness es un juego narrativo que fusiona mitología mesopotámica con elementos transhumanos. Exige personajes con transformaciones visuales ligadas a decisiones éticas, estética única y sistemas de animación que reflejan estados filosóficos.

Personajes clave: El Iniciado (protagonista con transformaciones éticas), Xlerion (IA transhumana), Ninhursag (deidad mesopotámica), Adamu (primer hombre).

🎯 Desafíos técnicos específicos

  • Blend Shapes para transformaciones éticas del Iniciado
  • Rig Humanoid para El Iniciado, Generic para Xlerion
  • Materiales dinámicos con Shader Graph
  • Barra de salud diegética en el modelo
  • Estética mesopotámica + bioluminiscencia
  • Cinemáticas interactivas con Timeline
Concept Art

Investigación de tablillas cuneiformes, sellos cilíndricos, relieves asirios. Fusionar con estética Giger y bioluminiscencia abisal.

Materiales Dinámicos

Shader Graph con parámetros expuestos: color de piel, emisión bioluminiscente, intensidad de transformación. Controlados desde scripts.

Narrativa Ramificada

Timeline + Cinemachine + ScriptableObjects para cinemáticas interactivas. Signals pausan la secuencia para elecciones del jugador.

Conclusiones Clave

1. El pipeline es un sistema integrado. Ninguna fase funciona aislada. Topología deficiente → deformaciones pobres. UV mal hecho → texturas distorsionadas. La excelencia AAA viene de la sinergia.

2. PBR y Channel Packing son estándares indiscutibles. Proporcionan consistencia y realismo. El empaquetado de canales reduce la carga de GPU al mínimo.

3. La optimización es proactiva, no reactiva. LODs, atlases y GPU instancing deben planificarse desde el inicio, no añadirse al final.

4. Unity es una plataforma seria para AAA. Con URP/HDRP, Animation Rigging, HLOD y la aplicación disciplinada de mejores prácticas, puede competir directamente en el ámbito AAA.
